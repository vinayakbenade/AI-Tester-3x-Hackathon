# bug-report-generation.md — Bug Report Draft SOP

## When Generated
Bug report drafts are generated by the LLM for entries with **Medium
severity or higher** only. Low-severity entries have `bugReport: null`.

## Required Fields
| Field | Description |
|---|---|
| `title` | Short, specific, no vague language |
| `summary` | 2-3 sentences describing the issue |
| `stepsToReproduce` | Best-effort from log context; state clearly if not derivable |
| `expectedVsActual` | What should happen vs what did happen |
| `severity` | Mirrors the entry's severity |
| `suggestedAssigneeArea` | Maps to the affected component |

## Export
Bug reports are formatted as JIRA-ready plaintext by `_generate_export.py`.
The "Copy as bug report" button in the UI copies this to the clipboard.
